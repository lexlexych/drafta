# Команда /finishEpic — финализировать эпик

Процедура для основной сессии (оркестратора). Аргумент — ID эпика.
Запускается **человеком** после того, как он проверил результат эпика и выполнил
ручные шаги из executive-summary-тикета. Команда закрывает статусы и вливает
ветку эпика в `main`.

## Шаги

1. **Нормализуй аргумент** (как в `/startEpic`): → папка `docs/epics/epic_NN/`,
   ID `E-0NN`, ветка `E-0NN`. Папки нет → покажи список эпиков из
   `docs/epics/STATUS.md` и остановись.
2. **Прочитай** `_index.md` эпика, `docs/epics/STATUS.md` и executive-summary-тикет.
3. **Проверь предусловия** по статусу эпика:
   - `manual_steps` → продолжай;
   - `todo` / `in_progress` → есть незавершённые dev-тикеты; сообщи, какие, и
     предложи `/startEpic E-0NN`. Остановись;
   - `blocked` → покажи причину (тикет `blocked` и замечания ревью). Остановись;
   - `done` → эпик уже финализирован; проверь `git branch --merged main` — влита ли
     ветка; сообщи состояние. Остановись.
4. **Сверь ручные шаги**: если в «Отметках о выполнении» executive-summary-тикета
   не все чекбоксы отмечены — перечисли неотмеченные и спроси пользователя,
   выполнены ли они. Подтвердил → отметь чекбоксы. Не подтвердил → остановись
   (без выполненных ручных шагов эпик не закрывается).
5. **Финализируй статусы** (находясь в ветке эпика `E-0NN`):
   - executive-summary-тикет → `done` (frontmatter + `_index.md` + `STATUS.md`);
   - эпик → `done`; в сводной таблице `STATUS.md` проставь дату завершения;
   - коммит: `[E-0NN] finish epic`.
6. **Влей ветку в `main`**:
   - рабочее дерево должно быть чистым (незакоммиченные изменения → спроси пользователя);
   - `git checkout main`;
   - `git merge --no-ff E-0NN -m "Merge epic E-0NN: <название по-английски>"`;
   - **конфликты молча не разрешай**: `git merge --abort`, покажи пользователю список
     конфликтующих файлов и спроси, разрешать ли агентом или он сделает это вручную.
7. **Не делай сам**: ветку `E-0NN` не удаляй, `git push` не выполняй — это по явной
   просьбе человека (упомяни обе опции в отчёте).
8. **Отчёт пользователю**: эпик закрыт и влит в `main` (hash merge-коммита),
   статистика тикетов (сколько dev, сколько циклов доработки было), опции
   (`git branch -d E-0NN`, `git push`), и что дальше — следующий этап через
   `/createEpic`.
