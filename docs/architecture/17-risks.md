# 17. Риски

> [!info] Навигация
> ⬅️ [16. План внедрения](16-rollout-plan.md) · ⬆️ [Оглавление](_index.md)

| Риск | Чем снижается |
|---|---|
| **Зависимость от Zernio** | [Слой адаптеров](05-channels.md) + сырые payload'ы в [`webhook_events`](06-data-model.md#webhook_events) делают переезд управляемым; DPA и список их субпроцессоров — обязательное входное условие [этапа 1](16-rollout-plan.md#этап-1--zernio-контур-входящие-2-4-дня) |
| **Ожидание генерации** | Черновик создаётся по нажатию, поэтому ожидание видно и ограничено одним вызовом модели: поле ответа блокируется со спиннером, рядом кнопка «стоп» ([`cancelOn`](07-data-flows.md#62-генерация-черновика)), а исчерпавший ретраи прогон помечает черновик `failed` и разблокирует поле |
| **Rate limit LLM в пиках** | [Конкурентность per-workspace](07-data-flows.md#пайплайн-генерации); при проблемах качества/квот Mistral — [OpenRouter как резервный провайдер](08-ai-subsystem.md#резервный-провайдер--openrouter) (переключение переменными окружения, с GDPR-оговоркой) или [Azure OpenAI EU Data Zone](08-ai-subsystem.md#клиент-и-выбор-провайдера) |
| **Модель называет не ту категорию** | Беседа уходит не под тот фильтр — и только: [категория](09-categories.md) больше не меняет набор файлов в промпте и не отменяет черновик. Черновик всегда проходит через человека, категории видны и над полем ответа, и в списке, текст категории уточняется итеративно. Стоимости у этого нет: категории приходят [тем же вызовом](08-ai-subsystem.md#контракт-ответа-categories), что и черновик |
| **Выдуманные факты в черновике** | Самый дорогой отказ: цена или срок, которых нет в базе знаний, уходят клиенту как обещание бизнеса. Снижается [заземлением промпта](08-ai-subsystem.md#заземление-и-отказ-от-выдумывания): закрытый список источников фактов, явный запрет приближать и обобщать, и отказной ответ `NEEDS_MANUAL_REVIEW` вместо правдоподобной догадки. **Остаточный риск** — модель всё равно может ошибиться, поэтому предохранитель прежний: черновик проходит через человека |
| **Рост стоимости Vercel** | Код переносим на Railway без изменений |
| **Push на iOS** | Работает только для установленной PWA, iOS ≥ 16.4 — [честно говорим в онбординге](11-realtime-pwa.md#web-push) |
| **Доставляемость auth-писем и email-канала** | Postmark + корректные DKIM/SPF/DMARC [с этапа 0](16-rollout-plan.md#этап-0--фундамент-1-2-дня) |
| **GDPR-риски** | [§15](15-compliance-gdpr.md): цепочка DPA, данные в ЕС, минимизация (только ID в Inngest, маскирование перед LLM), удаление/экспорт. **Остаточный риск** — юрисдикция Zernio до подписания их DPA |
| **Вайбкодинг-специфика: дрейф архитектуры и терминологии от сессии к сессии** | [Глоссарий](02-glossary.md) + [`CLAUDE.md`](14-vibecoding-rules.md) + тесты-контракты на адаптеры, RLS и маскирование как «несущие стены», которые агент не может незаметно сломать |
