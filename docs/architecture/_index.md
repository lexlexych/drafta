# Архитектурный план: AI-инбокс (PWA) — v5

> [!abstract] О документе
> SaaS-инбокс для малого бизнеса: переписки и комментарии из мессенджеров и соцсетей
> в одном месте, с автоматической генерацией AI-черновиков ответов.
> Рынок запуска — Германия/ЕС, поэтому GDPR-соответствие заложено в архитектуру
> с первого дня, а не добавляется потом.

Это оглавление (MOC — map of content). Каждая глава исходного плана вынесена в отдельный файл;
файлы связаны между собой ссылками в теле текста и полем `related` во frontmatter.
