# 11. Realtime, Web Push, PWA

> [!info] Навигация
> ⬅️ [10. UI и навигация](10-ui.md) · ⬆️ [Оглавление](_index.md) · ➡️ [12. Структура репозитория](12-repo-structure.md)

Экраны и навигация вынесены в отдельную главу — [10. UI и навигация](10-ui.md).

## Realtime

Подписка на `insert`/`update` в `messages` и `drafts` текущего workspace —
открытый инбокс живёт сам.

## Web Push

Через Serwist-воркер; отправка — Inngest-функции `send-push` и `push-digest`
([7.6](07-data-flows.md#66-полный-список-inngest-функций)), библиотека web-push, VAPID
(ключи — [13. Секреты](13-environments-secrets.md#секреты-vercel-env)).
Подписки хранятся в [`push_subscriptions`](06-data-model.md#push_subscriptions).

### Частота уведомлений — настройка пользователя

Каждый пользователь выбирает режим в разделе «Уведомления» настроек
([10. Разделы настроек](10-ui.md#разделы-настроек)); хранение —
[`notification_settings`](06-data-model.md#notification_settings):

| Режим | Поведение |
|---|---|
| **Каждое входящее** *(по умолчанию)* | Push при каждом новом сообщении/комментарии: «{имя} ({канал}) — Новое сообщение», клик открывает нужный диалог. Функция `send-push`; событие эмитит вебхук-пайплайн сразу после записи сообщения. Про черновик push не говорит — его ещё нет, генерацию запускает оператор |
| **Дайджест с интервалом** | Пользователь задаёт интервал (например, каждые полчаса). Cron-функция `push-digest` присылает сводку о новых входящих с момента прошлого дайджеста |

Формат дайджеста — **без LLM и без текста сообщений**: счётчики плюс краткий список,
например «5 новых сообщений, 2 комментария: Anna (WhatsApp Магазин), Max (Instagram)…».
Клик открывает инбокс.

> [!note] Почему в push нет контента переписки
> Push-payload проходит через инфраструктуру Apple/Google — держим там имена,
> названия каналов и счётчики, но не текст сообщений
> (минимизация данных — [15. Compliance](15-compliance-gdpr.md)).

> [!warning] iOS
> Push работает только для **установленной на экран** PWA (iOS ≥ 16.4) — отражаем в онбординге.
> См. [17. Риски](17-risks.md) и [Этап 9](16-rollout-plan.md#этап-9--pwa-и-push-1-2-дня).
