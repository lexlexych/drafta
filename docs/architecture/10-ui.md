# 10. UI и навигация

> [!info] Навигация
> ⬅️ [9. Категории входящих](09-categories.md) · ⬆️ [Оглавление](_index.md) · ➡️ [11. Realtime, Web Push, PWA](11-realtime-pwa.md)

> [!note] Уровень детализации
> Это верхнеуровневое описание структуры интерфейса. Детали экранов —
> состав дашборда, поведение списков, точные брейкпоинты — будут прорабатываться отдельно.

> [!example] Интерактивный макет
> Кликабельный HTML-прототип на mock-данных (каналы Instagram и Facebook, сообщения
> и комментарии, AI-черновики, контакты, настройки), адаптивный под мобильный и десктоп —
> [docs/references/ui-mockup.html](../references/ui-mockup.html). Открывается прямо
> в браузере, без сборки.

Одно PWA-приложение, адаптированное и к десктопным браузерам, и к мобильным устройствам.
Различается навигация; экраны и данные общие.

## Десктоп: левое меню

Слева располагается основное меню:

| Пункт | Поведение |
|---|---|
| **Дашборд** | Стартовый обзорный экран *(состав — при детализации)* |
| **Сообщения** | Клик по пункту — список сообщений **со всех каналов**. Опциональное расхлопывание — список всех каналов workspace под их пользовательскими именами ([5. Каналы](05-channels.md#несколько-каналов-и-имена)); рядом с каждым каналом — счётчик новых сообщений, суммарный счётчик — рядом с самим пунктом |
| **Комментарии** | По аналогии с «Сообщениями»: клик — все комментарии со всех каналов, расхлоп — по каналам со счётчиками новых |
| **Контакты** | Опциональное расхлопывание с разделением по каналам |
| **Настройки** | Расхлопывается на разделы настроек (таблица ниже) |

## Мобильный: нижняя панель

Те же основные разделы — иконками в меню внизу экрана (Дашборд, Сообщения, Комментарии,
Контакты, Настройки), со счётчиками-бейджами новых сообщений и комментариев.

## Откуда пришло входящее

Каналов одной платформы может быть несколько, поэтому в списках сообщений и комментариев
и в открытом треде всегда виден **именованный канал-источник** — бейдж с именем
[`channel_connection.name`](06-data-model.md#channel_connections).
Там же отображается присвоенная [категория](09-categories.md).

## Экраны инбокса

Общая механика двух ящиков ([1. Два ящика](01-overview.md#два-ящика)):

- **список слева** (для комментариев сгруппирован по постам)
- **тред в центре**
- **панель черновика** — принять / править / отклонить / сгенерировать заново

Раздел контактов: карточка, identities по каналам, кросс-канальная история, ручная склейка
([модель](06-data-model.md#contact_identities)).

## Разделы настроек

| Раздел | Содержимое |
|---|---|
| **Каналы** | Управление подключениями: добавить канал (OAuth-подключение через выбранную соцсеть, [5. Подключение аккаунта](05-channels.md#подключение-аккаунта-oauth)), задать/поменять имя, отключить; несколько каналов одной платформы ([5. Каналы](05-channels.md#несколько-каналов-и-имена)) |
| **Категории** | Создание/редактирование категорий, перестановка приоритетов ([9. Категории](09-categories.md)) |
| **AI** | Тон, язык, подпись, дебаунс, авто-генерация ([`ai_settings`](06-data-model.md#ai_settings)) |
| **База знаний** | md-файлы, редактор с превью ([8. База знаний в промпте](08-ai-subsystem.md#база-знаний-в-промпте)); *размещение внутри настроек — предварительное, обсудим при детализации* |
| **Команда** | Приглашения, роли ([4. Мультитенантность](04-multitenancy.md)) |
| **Уведомления** | Частота push: каждое входящее или дайджест с интервалом ([11. Web Push](11-realtime-pwa.md#web-push)) |
| **Приватность** | Экспорт и удаление данных ([15. Compliance](15-compliance-gdpr.md#123-технические-меры-уже-в-архитектуре)) |
